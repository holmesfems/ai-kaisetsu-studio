# アクセントの決め方（案を出すときの目安）

東京式アクセントで考える。アクセント句の中は「低→高→低」の形だけ（`l*h*l*`）。1拍目と2拍目は高さが違う（頭高 `hl…` か、低で始まって2拍目から高い `lh…`）。一度下がったら、その句の中では上がらない。

## VoiSona がよく間違える所と、直し方

| よくある崩れ | 例（今 → 案） | 直し方 |
|---|---|---|
| カタカナ名が細切れ | ヴィク・ト／リア | 辞書で1語に |
| 記号・英数字の読み | R2D2＝アール・ツー・ディー・ツー、M3＝エム・スリー | 辞書で読みと高低を決める |
| 複合語の途中で句が切れる | ホンライワン／パン、ブルー／ベリー | 区切りを動かす（chain）か辞書 |
| 句の中で2回上がる | ダ［メ］ージ［ジ］タイヲ、［エ］ス［イ］チ | 間で区切る（chain=0）か、後ろを低く |
| 下がった後に助詞・語尾が高い | ワ［ル］ク［ナ］イ、ツカエナ［ク］、ミ［マ］シタ、キ［レ］テ［イ］ル | 後ろを低く（hl を l に） |
| 助詞・補助動詞だけの全部低い句 | テツダッテ／クレマス、カイゴ／ダケデ | 前の句につなげる（chain=1） |
| 短い句に細切れ | ト／イ［ウ］／［ワ］ケデ | つなげて1句（ト［イウワ］ケデ） |
| 漢字の読み間違い | 他のメンバー＝タノ、一見＝イチゲン | 辞書（読みを変える） |

## 読みを変えるときの落とし穴

- **辞書の読みに「ヘ」を単独で書くと、助詞の「へ」（エと読む）にされる**：「無限幣」を読み「ムゲンヘー」で登録したら「ムゲンエー」になった。
  長音にしたいときも「ムゲンヘイ」のように書く（VoiSona が長く読む）。高低（accent）のモーラ数は同じ。
- **ハイフン入りの記号（MT-8 など）は、ハイフンの所で句が切れて間が空く**：読みを変える必要がある物（MT-10 → エムティージュー）は辞書で1語になる。
  読みは合っていて間だけが気になる物は、台本の文をルビ `｜MT-8《エムティーハチ》` にすると、字幕は MT-8 のまま1語で読む（文が変わるので、その行の手直しは外れる）。
- **読みを変えた行は、作り直して解析し直すまで、行の手直しを出さない**：手直しは今の解析結果（古い読み）ごと `_voice.json` に入り、
  手直し済みの行には辞書が効かなくなる。読みを変える辞書・ルビの回と、その行の高低を直す回は分ける。
- **辞書の高低はモーラ数と音素の数が合わないと当たらない**：「ウァン」は VoiSona が「ウ・ア・ン」の3音素にするので、2モーラの辞書（hl）が効かない。

## 言葉の種類ごとの目安
- **カタカナの名前**（人名・商品名など）：後ろから3拍目まで高く、そこで下がる（`lh…hll`）。ただし長音「ー」・促音「ッ」・撥音「ン」には下がり目を置かず、一つ前に移す（ミケランジェロ → ミケラ＼ンジェロ `lhhlll`）。短い名前は頭高（ケント、ハルカ、マリア）も自然。
- **〜券・〜者・〜性などの複合語**：前の部分の最後で下がる（割引券 ワリビキ＼ケン `lhhhll`）。長い複合語は全体を1句にする（特別割引券 `lhhhhhhhll`）。
- **「新型」「旧型」＋スマホ**などの言葉の組み合わせ：1語として扱い、後ろの語のアクセントで下がる。
- **A1〜A3 のような記号＋数字**：1語にする（エーイチ・エーニ・エーサン）。
- **数＋助数詞**（35人、12月14日など）：VoiSona の分け方のままでよいことが多い。ユーザーは 35人 を「サンジュー／ゴニン」のままにした。
- **文末の「〜ですね」「〜ます」**：下がった後なので低いまま。平板の言葉の後なら「デ［ス］ネ」と上がったままでよい。
