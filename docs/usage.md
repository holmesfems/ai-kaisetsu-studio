# 使い方の詳細

[README](../README.md) の続き。画面の見方・演出の微調整のしくみ・効果音・字幕・書き出し・Claude Code とのつなぎ方・ファイルの置き場所。
演出の kit は [kit.md](kit.md)、台本の書式は [script-format.md](script-format.md)。

## 画面

| 場所 | 中身 |
|---|---|
| 左: 台本 | `script/<名前>.yaml`（ブロックごと。行は id・sp・start・text・memo。書式は `docs/script-format.md`）を読み書き（自動保存・上書き前は `_backup/`）。声のアクセント・抑揚の手直し（`_voice.json`・`_voice_params.json`）は行の id が鍵で、文や話者を直すと使われなくなる（行に「前の文の調整」と出て、✕ で消せる）。古い回（`.md` の表）は開いたときに `_backup/<日時>-v2/` に写して YAML に移す。開始が書いてある行は動かさず（前の行と重なるときだけ押し出す）、間隔は開始の無い行と「詰め直す」で使う。間隔は初めて開いたときに台本から見積もる。▶ で声を作って再生、A でアクセント・長さ・抑揚（声のエンジンが VoiSona Talk のとき。ほかのエンジンでは、そのエンジンができるものだけ出る）。行番号のクリックで選ぶと、Claude に送るときの文脈になる。「取り込む…」（script/ の無い回では「ほかの回から取り込む…」）で、ほかの回の台本からブロック・行を、アクセント・抑揚の調整、メモ、話者の声の設定ごと末尾に足せる（開始時刻は写さない。取り込み元は書き換えない）。「メモ」ボタンで行の下に Claude 向けのメモ（例: 「ここで実際のPUメンバーを出す」）を書ける。各行の `memo` に保存し、読み上げ・字幕・`script.srt` には使わず、Claude が演出を作るときだけ参考にする |
| 左: 構成メモ・素材 | `_memo.md`。素材（立ち絵・録画・BGM）をタイムラインに置く。エクスプローラーからタイムラインへのドロップでも置ける |
| 中: モニター | 背景・録画・立ち絵・演出・字幕を重ねたプレビュー。演出をクリックで選び、ドラッグで移動・右下の角で拡大。字幕をクリックでそのセリフを選ぶ。シーン番号・ガイド（立ち絵 x<600、字幕 y>880、演出のステージ、字幕の左右の目安線＝はみ出すと赤） |
| 右: 調整 | 選んだ演出クリップの微調整（ずらす・長さ・位置・大きさ・不透明度・重なり順・隠す）とコード。素材の位置・スケール・フェード・音量・話者（話していない人の立ち絵を暗く）。セリフの字幕（改行・フォント・大きさ）、字幕の見た目（共通・話者ごと） |
| 右: Claude | チャット、Claude の推敲案（差分を見て 1 件ずつ採用）、つなぎ方の案内 |
| 下: タイムライン | 映像トラック・演出（`add(...)` 1 回 = 1 クリップ）・cue と同期点・字幕・話者ごとの声・効果音・BGM。ドラッグでずらす、端で長さ、スナップ、レンダリング済みの帯（緑） |
| 効果音の設定 | タイムラインの「効果音」の ⚙（か SE の印のクリック）で右に出る。演出の動きの種類（章タイトル・ハンコ・ワイプなど）ごとに、候補の音を ▶ で単体試聴・「前後を聞く」で声・BGM と一緒に試聴し、候補ごとの音量（標準の大きさからの dB）を変えて、鳴らす音を選ぶ（複数なら順番に使う）。「保存して反映」で `fx/se/bank.json` に書き、効果音を作り直す |
| 録画を差し込む（ネスト） | タイムラインの RecWindow（録画の窓）をダブルクリックで開く。窓の大きさ・枠を見ながら、その窓が出ている区間だけのタイムラインに録画・画像を置く（複数トラック・移動・両端のトリム・分割 S・複製 Ctrl+D・削除 Delete、PLAYBACK の切り替わりと再生位置にスナップ）。Premiere のネストと同じく、自分のキャンバス（既定 1920x1080、変えられる）の外は捨て、キャンバス全体を窓に「収める / 引き伸ばす / 埋める」ではめる |

キー: Space 再生、J K L、←→ 1 コマ（Shift で 1 秒）、↑↓ 前後のセリフ・シーン、I O イン・アウト、Enter レンダリング、
Delete 選んだ演出を隠す、Ctrl+Z 元に戻す（自分の操作だけ）、Ctrl+Alt+Z Claude や外のエディタでの変更を戻す（Claude タブの「外での変更」から 1 件ずつも戻せる）、B（押している間）一番新しい外の変更の前の姿をモニターで見比べる、タイムラインのホイールは左右スクロール（Shift で上下、Alt でズーム。
Ctrl+ホイール・タッチパッドのピンチでもズーム）。

## 演出の微調整のしくみ

- `fx/<名前>_fx.py` の `build()` の中の `add(...)` 1 回を 1 クリップとして扱う。キーは `部品名@c<cue>#<順番>`
  （`telop@c15#1`）で、コードの行が動いても変わらない
- 手で直した値は `fx/studio_overrides.json` に入り、コードは書き換えない
  （`{"telop@c15#1": {"shift": 0.2, "end": -0.5, "dx": 30, "dy": -10, "scale": 1.1, "opacity": 0.9, "hidden": false}}`）
- 画面から足した簡単な演出（テロップ・注釈・ハンコ・キーワード）は `fx/studio_clips.json`
- RecWindow に差し込んだ録画は `studio/project.json` の `nests`（キーは RecWindow のクリップのキー）。合成では演出の下・窓の中だけに描き、
  素材が入っている区間は微調整の `no_placeholder: [[開始, 終わり], …]`（自動で書く）で窓の仮表示（ファイル名・説明）を消す
- 「台本 → 演出の入力」の書き出しは、メモのある行を `files/script_memo.json`（`[{"cue", "sp", "text", "memo"}]`。cue は `script.srt` の番号。メモが無ければ `[]`）にも書く。
  あわせて `files/script_cues.json`（`{"cues": [{n, start, end, text, speaker}]}`。演出の fxkit が読む cue の表。`script.srt` と同じ時刻）も書く
- 台本の行を足す・消す・並べ替えて「台本 → 演出の入力」を書き出すと、cue 番号がずれる。そのときは前の `script.srt` と今のセリフを
  `[話者] 文` で突き合わせて（同じ文・動かした文・文を直しただけの行・似た文の順）、`studio_overrides.json` と `nests` のキーの
  `@c<古い番号>#` を `@c<新しい番号>#` に付け替える（付け替えた数は書き出しの警告に出る）。演出のコードの `c(n)` を新しい番号に
  直すと、調整と録画が同じクリップに付く（直すまでは別のクリップに付いて見える）。`gui:` のキーはそのまま
  - 書き換える直前に、そのファイルの控えを `studio_overrides_<日時>.json`・`project_<日時>.json` に保存する（保存できなければ付け替えない）
  - 削除した行に付いていたキーは付け替えずに残し、警告に名前を出す。付け替えたキーと同じ名前になるものは削除して、警告に名前を出す
  - 付け替えに失敗したときはエラーの知らせを出す（script.srt はもう新しいので、やり直さない。キーは手で直す）
  - 前の `script.srt` が読めない（UTF-8 でない・cue 番号が順でないなど）ときと、AK Studio の外（split_talk.py など）で
    `script.srt` を書き換えたときは付け替えない。演出は `script_cues.json` を読むので、srt だけ書き換えても演出には効かない
- コマのキャッシュの鍵は「そのコマに出ているクリップの中身の指紋＋微調整」。1 つ直しても、ほかの場面のキャッシュはそのまま
- `fx/*.py`・`files/script.srt`・`files/script_cues.json`・`sync_points.json` が書き換わると自動で読み直す（Claude がコードを直したときも）

## 効果音の設定

演出の動き（`add(...)` の要素）から、fxsound が種類（kind）ごとに効果音を付ける。どの音を鳴らすか・どの大きさかは回の
`fx/se/bank.json` に書く（fxsound.load_bank と同じ形に、AK Studio の `_studio` を足したもの）。

```
{"slam": ["H9.wav"],                                   ← 鳴らす候補（複数なら出てくる順に順番に使う。無ければ合成の音）
 "_studio": {"cands": {"slam": ["H7.wav"]},            ← 鳴らさないが候補として並べておく音（鳴らすのをやめた音もここに残る）
             "db": {"slam": {"H9.wav": -3, "synth": 2}}}}  ← 候補ごとの音量（標準の大きさからの dB、−30〜+24）
```

- 候補は `fx/se/` の下の .wav（16bit PCM。ほかの形式は候補に出ても選べず、「ファイルから…」でも断る）。`fx/se/<種類>/` に置いた .wav は、その種類の候補に自動で出る（画面の「ファイルから…」もそこに写す）
- 音量は、fxsound が種類ごとにそろえる標準の大きさ（素材の音も合成の音の大きさに合わせる）からの dB。AK Studio の書き出しで効く
- 数え上げのカチカチは合成の音だけ（音量だけ変えられる）。確定音は「数え上げの確定」で選ぶ
- Claude からは MCP の `se_list` / `se_set`（HTTP は `GET /api/se`・`POST /api/se/set`）

## 字幕

字幕は台本のセリフ（声の並び）から作り、Python（PIL）で 1 枚の絵にしてから重ねる。モニター・完成版 mp4・確認画像（Claude 用）・
字幕の透過 .mov が同じ絵を使うので、見た目がずれない。既定の見た目は今までのチャンネルの字幕（
Noto Sans JP 900・54px・白・縁 6px の青・最後の行の下 y=1060・行の間隔 70・幅 1500 で折り返し）。

- 見た目は 3 段で重ねる: 共通（タイムラインの「字幕」の ⚙）→ 話者ごと（声の行の ⚙。例：トーク2 だけ縁の色を変える）→ セリフごと
- 共通・話者: フォント（入っているフォントから。可変フォントは太さも）・大きさ・文字の色・縁の色と太さ・影・下の位置・行の間隔・左右の余白・揃え・自動の折り返し
- セリフごと（セリフを選んで右の「字幕」）: 改行の場所（Enter で改行。改行を入れた行は自動で折り返さない）・フォント・大きさ。
  改行以外も変えると「字幕だけ書き換え」（声は台本のまま）
- セリフごとの設定は `studio/project.json` の `subtitle_lines`（鍵は「話者 + 字幕の文」）。台本の文を直すとその行の設定は外れる
  （字幕の見た目の画面に数が出て、「掃除」で消せる）
- 左右の余白が「収めるべき線」。モニターのガイドに緑の点線で出て、はみ出した行は赤くなる（タイムラインの字幕も赤）
- タイムラインの「字幕」の 👁 で字幕を出さない（モニター・書き出しの両方）。モニターの「字幕」ボタンは見え方だけ

## 書き出し

| 書き出し | 出力 |
|---|---|
| 台本 → 演出の入力 | `files/script.srt`（[話者] つき。Premiere 用）、`files/script_cues.json`（演出の fxkit が読む cue の表）と `files/talk/<話者>/<番号>.wav/.txt`、`voice_out/`（フル WAV・話者別）。cue 番号がずれたら警告。台本の声の開始と script.srt の cue の時刻が 0.05 秒より食い違うと、トップバーとタイムラインの CUE 行に警告が出て、そこからも書き出せる |
| 効果音 | `fx/out/<名前>_se.wav` ＋ `se_stems/`（微調整のずらし・効果音の設定の音と音量も反映） |
| 演出 .mov | `fx/out/<名前>.mov`（確認用）／`<名前>_clean.mov`（本番用）。0 秒始まりの透過 qtrle。区間だけなら `_<開始>-<終わり>s` つき |
| 確認用・完成版 mp4 | `studio/export/`。背景・録画・立ち絵・演出・字幕・声・効果音・BGM（NVENC があれば使う） |
| 録画トラック mp4 | `studio/export/material_track.mp4`。RecWindow に差し込んだ録画だけを黒の 1920x1080 の窓の位置に置いたもの（0 秒始まり・演出と同じ長さ。Premiere で演出の下に敷く） |
| 字幕 .mov（透過） | `fx/out/<名前>_subs.mov` ＋ `_subs.srt`（演出のタイムラインが無ければ `studio/export/<回>_subs.mov`）。字幕だけの 0 秒始まりの透過 qtrle。Premiere の頭に置くだけ |
| 字幕 .srt | `fx/out/<名前>_subs.srt`。手で入れた改行・自動の折り返し・字幕だけの書き換えをそのまま入れる（演出の入力の `files/script.srt` とは別） |

## 声のエンジン

声は、⚙ 設定の「声のエンジン」で選んだソフトで作る（VoiSona Talk・VOICEVOX・自作の `.py`）。保存すると声の中継を起動し直し、上の帯の丸がそのエンジンの名前になる。
エンジンごとに声のキャッシュは別で、戻せば前の声がそのまま鳴る。できること（アクセントの手直し・音素の長さ・抑揚・スタイル）はエンジンごとに違い、できないものは画面に「使えません」と出る。
約束・同梱のエンジンの準備・自作のエンジンの作り方は [voice-engine.md](voice-engine.md)。

## Claude Code とつなぐ

右の「Claude」タブ（か ⚙ 設定）の「Claude Code に登録」を 1 回押すと、

- MCP サーバー `ak-studio`（ユーザー全体）: 台本を読む・推敲案を出す・演出クリップの一覧と微調整・確認画像（1 コマ・cue ごとのコマを並べた 1 枚）・推定の同期点の一覧・演出の読み直し・効果音の設定・返事・書き出し
- Mod `ak-studio`（`claude-plugin/` をフォルダのマーケットプレイスとして登録）: プロンプトの上に AK Studio の状況の帯
  （回・再生位置・シーン・選んでいるクリップと行・推敲案）。回のフォルダで動くセッションと自動でつながり、
  画面のチャットで送ったメッセージを `$.prompt.submit` でそのセッションに届ける（待機中なら動き出す）。`/studio on|off`。
  Claude の作業中は、何をしているか（台本を読んでいます など）を画面のチャットの下に Clawd 風のドット絵つきで出す（`POST /api/agent/activity`）

が入る。「Claude を起動」で、その回のフォルダで Claude Code が開く。

Mod は `claude-plugin/` がマーケットプレイス `ak-studio-local`。公開の `ak-studio` は、状況の帯・チャットの中継のフック、声のアクセントのスキル `voisona-accent`（VoiSona Talk のとき）を持ち、これだけで動く。
演出・企画のスキルを kit と一緒に Mod にしたものがあれば、同じ方法で入れる。

```
claude plugin marketplace add <リポジトリ>/claude-plugin
claude plugin install ak-studio@ak-studio-local -s user
```

メッセージの届け方は ⚙ 設定で選べる:

| 届け方 | しくみ | メモ |
|---|---|---|
| Mod（既定） | Mod が 1.5 秒おきに受け取り、`$.prompt.submit` | 状況の帯も出る |
| フック | 回のフォルダの `.claude/settings.local.json` に、`SessionStart`・`Stop` で待ち受け（`ak-studio-mcp --wait`、`asyncRewake`）、`UserPromptSubmit` で画面の状況を添える（`--context`） | Mod が使えないとき |
| channels | `claude --dangerously-load-development-channels server:ak-studio` | 組織の設定で Channels が有効な場合（Organization settings → Claude Code → Channels） |

送り間違えたら、送った直後にチャット（入力欄か履歴）で **Esc** か **Ctrl+C**（文字を選んでいないとき）、
またはメッセージの「取り消し」で取り消せる。文は入力欄に戻る。

- 送ったメッセージは ⚙ 設定の「取り消しの猶予」（既定 3 秒）のあいだ AK Studio で待たせてから Claude に渡す。
  Mod は Claude の作業中は受け取らない（作業が終わるまで AK Studio に置いておく）。フックも、待ち受けは作業の合間だけ。
  まだ渡していなければ、取り消すと Claude には届かない（「取り消し（Claude には届いていません）」）
- もう届いていたら、Claude に「直前のメッセージは無視して。手を付けていたら止めて、何をしたか伝えて」と知らせる。
  Mod なら、そのメッセージ 1 通で始まった作業中のターンは `$.turn.abort` で止め、知らせは次のメッセージに添える

### モニターの印（場所つきで Claude に伝える）

モニターの見出しの「✎ 印」で描くモードに入り、直してほしい所に印（ピン・矩形・矢印・ペン。色は赤＝直して・黄＝注目・緑＝良い（残す）・水色＝参考）を描く。
描いたらその場で一言を入れる（Enter で決定・Esc でなし）。印は番号つきで、タイムラインの「印」の行に区間の帯が出る
（描いたときのシーンの長さ。帯の両端のドラッグで変え、クリックでその印へ移動）。描くモードでは印の線をクリックして選び、
一言・色を直したり、Delete か「消す」で消したり、「済にする」「戻す」ができる。Esc で描くモードを抜ける。見出しの「印」は表示の入り切り（書き出しには出ない）。

チャットの入力欄に「✎ 印 ①②」のチップが出るので、そのまま送る（チップの ✕ でその送信だけ外せる。「画面の状況を添える」を切っても印は添える）。
Claude には、印ごとの座標・区間・下にある演出クリップ／素材と、印を重ねた確認画像（`studio/chat/mark-*.jpg`）が届く。
送った印は「送信済み」で残り、Claude が直したら済にする（モニターでは薄く＋✓、Claude の印は破線）。送った直後に取り消すと印は下書きに戻る。
印は回の `studio/marks.json` に保存される。

ローカル HTTP API（Claude 用）は `127.0.0.1:47815`（使用中なら空いている番号）。ポートと合言葉は
`%LOCALAPPDATA%\ak-studio\session.json`。外から画面のチャットに書くには `POST /api/chat/user {"text": …}`。
