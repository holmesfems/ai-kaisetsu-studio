# 台本の保存形式（v2: YAML ＋ 行の id）

AK Studio だけで台本を書く前提の形式。台本エディタ（script_editor.html）の `.md` の表は、古い回を開いたときに読み込んで移すだけ。

## 1. 台本のファイル（`<回>/script/<名前>.yaml`）

ブロック（見出し）ごとに 1 ファイル。並びは今までどおり `_order.json`（ファイル名の配列。拡張子は `.yaml`）。
`_` で始まるファイルは台本ではない（`_memo.md`・`_order.json`・`_voice*.json`・`_backup/`）。

```yaml
title: "200枠と75枠"   # 先頭が ASCII（数字）なので引用符
notes: |-
  画面に出すもの：#1〜2 200枠のカードを並べる
  #5〜8 サンプル 75
lines:
  - id: l51x9k
    sp: トーク2
    start: 209.45
    text: 山田、田中、佐藤、鈴木、W。どれも少し前の限定キャラですね
    memo: |-
      ここで実際の交換対象5人の立ち絵を並べる
      名前は｜で区切る（a|b）
  - id: l52x9k
    sp: トーク1
    text: この中だと、山田は、バフが欲しいなら取ってもいいぐらいです
```

- 行のキーの順は `id, sp, start, text, memo`。`start`（開始秒。小数 3 桁まで）と `memo` は無ければ書かない。`notes` も空なら書かない
- `id` は台本全体で重ならない文字列（英小文字と数字。先頭は英字）。画面・Claude・アクセントの道具は行をこの id で指す。
  一度付けた id は、文や話者を直しても、行を動かしても、ファイルをまたいで移しても変えない
- 読むとき: `id` が無い行・ほかの行と重なる id の行には、新しい id を付ける（手で行を足したとき）。知らないキーは捨てずに残さなくてよい（v2 では無視）
- 書くときの文字列（AK Studio は自前で書き出す。決まった形で、差分が小さくなるように）:
  - 改行を含む文字列（`notes`・`memo`）は `|-` のブロック（末尾の改行が要るときは `|`）。各行の先頭・末尾の空白やタブ・制御文字があるときは、ブロックをやめて二重引用符
  - それ以外は、次をすべて満たすときだけ引用符なし: 先頭の文字が ASCII でない（日本語・全角）か、id の形（`^[a-z][a-z0-9]*$` で、`y n yes no on off true false null` ではない）／`: ` と ` #` を含まない／`:` で終わらない／前後に空白が無い／制御文字が無い
  - それ以外は二重引用符（JSON と同じエスケープ。YAML の二重引用符として読める）
  - PyYAML（YAML 1.1）と Rust のどちらで読んでも、書いたとおりの文字列に戻ること（`yes`・`1:20`・`0x10` などが数や真偽値にならないこと）
- 読み込みは YAML として正しいものなら何でも読む（人や Claude が手で直したもの）

## 2. 行ごとの声の調整（`_voice.json`・`_voice_params.json`）

鍵を **行の id** にする。調整は、作ったときの話者と読み上げの文（`tts_text(text).trim()`。ルビは読み）も持つ。
**今の行の話者と読み上げの文が、持っている sp・text と同じときだけ効く**（文を直したら、その調整は使われなくなる。文を元に戻せばまた効く）。

```json
// _voice.json（アクセントの手直し。analyzed_text は VoiSona の解析結果の XML）
{"l51x9k": {"sp": "トーク2", "text": "山田、…ですね", "analyzed_text": "<acoustic_phrase>…"}}

// _voice_params.json（抑揚・音素の長さなど。params の中身は今までの値そのまま）
{"l51x9k": {"sp": "トーク2", "text": "山田、…ですね", "params": {"intonation": 1.2}}}
```

- 使われなくなった調整（文が違う・行がもう無い）も、ファイルからは消さない（元に戻したとき・元に戻す操作のため）。
  画面は、使われていない調整がある行に「前の文の調整（使っていません）」と出し、✕ で消せる
- 声のキャッシュ（`voice_cache/`）の鍵は今までどおり中身（話者・文・手直し・抑揚・辞書）で決まる。id は入らない
- `_voice_speakers*.json`（話者ごとの声。声のエンジンごとのファイル）と `_memo.md` は変えない
- ほかの回から取り込んだ行（台本タブの「取り込む…」）は新しい id になり、元の行の調整を中身ごと新しい id の鍵に写す（sp・text は同じなのでそのまま効く）。
  取り込み元の回は一時フォルダに写してから読むので、古い `.md` の回でも書き換えない

## 3. 古い回（`.md` の台本）からの移し方（AK Studio が回を開いたとき）

`script/` に `_` で始まらない `.md` があり、同じ名前の `.yaml` が無ければ、移す:

1. 移す前の `*.md`・`_order.json`・`_voice.json`・`_voice_params.json` を `script/_backup/<日時>-v2/` に写す（写せなければ移さずにエラー）
2. 各 `.md` を今までの決まり（表・見出し・メモ列・表の外の文はブロックのメモ `notes`）で読み、行に新しい id を付けて `<同じ名前>.yaml` に書く
3. `_voice.json`・`_voice_params.json` の古い鍵（`話者 + "\u0001" + 読み上げの文`）を、その鍵に合う行すべての id に移す（同じ文の行が 2 つあれば、両方に同じ調整）。どの行にも合わない古い鍵は捨てる（控えには残っている）
4. `_order.json` の `.md` を `.yaml` に直す。`.md` を消す
5. 画面に「台本を新しい形式（YAML）に移しました。前のファイルは script/_backup/… にあります」と知らせる

古い形の判定: `_voice.json`・`_voice_params.json` は、鍵に `\u0001` を含むものがあれば古い形。
同じ名前の `.md` と `.yaml` が両方あるときは `.yaml` を使い、`.md` は触らずに警告を出す。

## 4. 台本を読むほかの道具

- `voice/akscript.py`: 台本（YAML）と声の調整を読む共通の部品。`voice_report.py`・`voice_review.py` はこれを使う。
  `.md` しか無い回では「AK Studio でこの回を開くと新しい形式に移ります」というエラーで止まる
- `voice_review.py` の draft.json・result.json は、行を `id` で指す（`file`・`no` は表示のためだけに残す）。書き込みは 2. の形
- `script_editor.html` は使わない。`.yaml` の台本がある回は開かない（開こうとしたら知らせて止める）
- 演出の道具（`script.srt`・`files/talk/`・`files/script_memo.json`）は変わらない
